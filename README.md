# Loan-Risk-Analysis-Dashboard
Detailed analysis and EDA of bank loan dataset using python and converting the same insights into presentable dashboard using Power BI. It explains which category gives more loan to people and who are more likely to avail the loan facility.
First the dataset was uploaded into MySql and checked for the redundancy of data. Then it has been cleaned using Python and some detailed analysis have been done. The cleaned dataset was then exported into Power BI and dashboard was created based on this cleaned dataset.
